分群演算法視覺化

透過動畫探索 KMeans、DBSCAN 與 HDBSCAN

K-Means 分群

一種基於中心點的演算法，將 n 個觀測值劃分為 k 個群組。

  • 階段： 初始化
  • 迭代次數： 0
1. 隨機放置 K 個中心點。
2. 將每個點分配給最近的中心點。
3. 將中心點移動到所屬點的平均位置。
4. 重複直到收斂。

DBSCAN

具雜訊點的基於密度空間分群 (Density-Based Spatial Clustering of Applications with Noise)。

  • 狀態： 等待中
  • 雜訊點數量： 0
1. 選取一個尚未訪問的點。
2. 搜尋半徑 (Eps) 內的鄰居點。
3. 若鄰居數小於門檻 (MinPts)，標記為雜訊。
4. 否則，啟動新分群並遞迴擴展。

HDBSCAN

💡 初學者導讀：

想像你在看雲朵。DBSCAN 像是在固定距離看雲，但 HDBSCAN 則會從遠處（宏觀）一直拉近到近處（微觀）來觀察密度變化。

  • 目前狀態： 等待中
1. 測量密度 (Core Distance)

計算每個點周圍有多擠。點越擠，它的核距離越短。

2. 連結鄰居 (MST)

把點連在一起，但會考慮密度的影響，不讓稀疏區的點干擾核心。

3. 建立家譜 (Dendrogram)

看群組如何隨密度增加而分裂或合併，形成一個階層樹。

4. 選取最終群組 (Stability)

像是在家譜中選出最「穩定」的成員，而不是只切一刀。
