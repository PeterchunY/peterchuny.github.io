分群演算法視覺化

透過動畫探索 KMeans、DBSCAN 與 HDBSCAN

K-Means 分群

一種基於中心點的演算法，將 n 個觀測值劃分為 k 個群組。

  • 階段： 初始化
  • 迭代次數： 0
1. 隨機放置 K 個中心點。
2. 將每個點分配給最近的中心點。
3. 將中心點移動到所屬點的平均位置。
4. 重複直到收斂。

DBSCAN

具雜訊點的基於密度空間分群 (Density-Based Spatial Clustering of Applications with Noise)。

  • 狀態： 等待中
  • 雜訊點數量： 0
1. 選取一個尚未訪問的點。
2. 搜尋半徑 (Eps) 內的鄰居點。
3. 若鄰居數小於門檻 (MinPts)，標記為雜訊。
4. 否則，啟動新分群並遞迴擴展。

HDBSCAN 分群詳解

目前狀態： 等待中

💡 核心觀念：

與其問「距離半徑10 公分內有哪些點？」，HDBSCAN 問的是：「要讓這兩個點連起來，最少需要多高的密度？」換言之，更在意「兩點連線是不是在密集區內成立」，而不是只看距離是不是小於某個固定值。

1. 重新定義距離 (Mutual Reachability)

如果一個點在稀疏區，周圍不夠擠，那它就不該輕易跟別人連成群。這樣核心密集的區域才會更突出。

2. 把所有點串成一張“最省力”的網 (MST)

根據新距離把把所有點連起來，形成一張網。最容易連起來的，就是密度最高的群組核心。

3. 慢慢把標準收緊：看大網怎麼裂成小網 (Dendrogram)

調整「密度門檻」，隨著密度門檻提高，大網會斷裂成小網。我們記錄下所有可能的「群組分支」。

4. 留下“長壽且穩定”的群 (Stability)

有些群分支一下就消失了（雜訊），有些則在各種密度下都存在。我們只保留那些「長壽且穩定」的群組。

🔍 HDBSCAN vs. DBSCAN 深度對比

📡 DBSCAN (固定視野)

需要預先設定一個固定的半徑 eps。這就像是戴著一副固定度數的眼鏡，只能看清特定距離的群組。如果資料中同時存在「極密集」和「較稀疏」的群組，DBSCAN 往往只能抓到其中一種，另一種會被當成雜訊或糊在一起。

🔭 HDBSCAN (變焦鏡頭)

不預設固定半徑，而是掃描所有可能的距離。它會找出在各種尺度下都能「穩定存在」的群集。你只需要告訴它：「一個群組最少要由幾個點組成 (min_cluster_size)」，它就會自動幫你找出最合理的各級分層。

💡 核心結論： HDBSCAN 更在意「點與點之間是否有高密度的路徑連通」，而非單純的物理距離。這讓它在處理複雜分佈的資料時，比 DBSCAN 強大得多。
